# Scrubby

A minimal Godot 4.7.2 GDScript project, ready for a game idea and iterative prototyping.

## Prerequisites

- Godot 4.7.2 standard edition.
- Node.js, Python, and `uv` for BMad Game Dev Studio.

Open `project.godot` in Godot or Xogot and run the main scene. The scene is intentionally empty.

GDScript supports Godot web export and Xogot on iPad. Test web builds on the target browser and device.

## Agentic workflow

BMad Game Dev Studio provides game-specific design and development workflows for GitHub Copilot. Start with `/bmad-help` for guidance or `/gds-quick-dev` for a prototype. Use `/gds-gdd` when a game design document is useful, and playtest each iteration in Godot.

The BMad Game Dev Studio installation is complete. Reload VS Code if its skills are not available in chat.

See the [BMad Game Dev Studio documentation](https://github.com/bmad-code-org/bmad-module-game-dev-studio) for its full workflow.
